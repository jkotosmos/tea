# Нарек Погосян — личный сайт

Одностраничный сайт-визитка предпринимателя и архитектора бизнес-систем.
Статика без сборки и зависимостей: открывается как файл, публикуется
на GitHub Pages как есть.

**Адрес:** https://jkotosmos.github.io/tea/

---

## Идея оформления

Сайт собран как **лист рабочей документации**. Это не украшение ради
украшения: человек семнадцать лет сдаёт объекты по чертежам, и язык
чертежа — его собственный язык.

Отсюда всё остальное:

- **рамка листа** с угловыми засечками и координатными метками по краю;
- **штамп** в правом нижнем углу — как на чертеже. Он живой: показывает
  номер и название текущего листа, пока вы листаете. На узких экранах
  превращается в полосу по низу;
- **корешок** слева с номерами листов 01–09 — навигация по разделам;
- **размерные линии** (`|←— 17 лет в стройке —→|`) вместо декоративных
  разделителей;
- кейсы — не карточки, а **реестр объектов**: таблица с параметром, сроком
  и суммой, строки раскрываются;
- цифры — **ведомость показателей**, как в смете;
- миллиметровка на фоне, тонкие линейки, прямые углы.

Ограничения выдержаны намеренно: ни одной тени, ни одного скругления,
ни одного градиента, ни одного эмодзи. Один акцентный цвет — приглушённый
кирпичный. Всё остальное делает типографика и воздух.

### Цвет и шрифт

| | Светлая тема | Тёмная тема |
|---|---|---|
| Бумага | `#f4f1ea` тёплый бумажный | `#121110` антрацит |
| Текст | `#17140f` | `#efeae0` |
| Акцент | `#a4441c` кирпич | `#d2703f` |

Тема переключается в штампе и запоминается в браузере; по умолчанию
берётся системная.

- **IBM Plex Sans** — заголовки и названия объектов
- **IBM Plex Mono** — технические подписи, цифры, штамп
- **PT Serif** — длинные тексты и цитаты

Шрифты лежат в `fonts/` локально. Сторонних запросов страница не делает
вообще — ни шрифтов, ни аналитики, ни счётчиков. Подробности —
в [`fonts/README.md`](fonts/README.md).

## Структура

```
index.html          весь текст сайта — правится здесь
css/style.css       оформление
css/fonts.css       объявления @font-face (собран скриптом)
fonts/              18 файлов .woff2, ~300 КБ
js/main.js          тема, счётчик листов, подсветка корешка
img/                пусто — сюда класть фотографии
robots.txt
sitemap.xml
```

Разделов девять, у каждого свой `id` и номер листа:

| Лист | Раздел | Что внутри |
|---|---|---|
| 01 | Обложка | имя, дескриптор, три ключевые цифры |
| 02 | Позиция | кто, что делает, формула «понимание = ясность = система» |
| 03 | Ведомость | показатели и строка заказчиков |
| 04 | Метод | картирование проекта в 8 шагов, центробежные и центростремительные |
| 05 | Реестр объектов | 12 кейсов с цифрами, строки раскрываются |
| 06 | Экспертиза | четыре направления |
| 07 | Выступления | темы и форматы |
| 08 | Рамки | что здесь есть и чего здесь нет |
| 09 | Связь | каналы |

Сайт полностью работает без JavaScript: без него не будет только
переключателя темы и живого счётчика листов, весь текст и раскрытие
строк реестра останутся на месте.

## Что нужно доделать

**1. Фотографии.** Папка `img/` пустая. Сайт спроектирован так, чтобы
работать и без снимков, но реальный кадр с объекта его усилит. Готовая
разметка лежит закомментированной в `index.html` (лист 02) — положите файл
в `img/` и снимите комментарий:

```html
<figure class="shot">
  <img src="img/portret.jpg" alt="Нарек Погосян на объекте"
       width="1200" height="1500" loading="lazy" decoding="async">
  <figcaption>Подпись: объект, город, год</figcaption>
</figure>
```

Стили (`.shot`) уже написаны: рамка в линию и обесцвечивание —
по документальной подаче из брифа. Нужны реальные кадры со стройки,
не сток.

**2. Обложка для соцсетей.** `og:image` намеренно не проставлен: картинки
нет, а ссылаться на несуществующий файл хуже, чем не ссылаться совсем.
Когда появится — положите `img/og-cover.jpg` (1200×630) и добавьте в `<head>`:

```html
<meta property="og:image" content="https://jkotosmos.github.io/tea/img/og-cover.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
```

**3. Подписи к YouTube-каналам.** Каналов два, и подписаны они со слов
владельца: `@GK-REMESLO` — компания, `@gpt-remeslo` — ИИ и автоматизация.
Проверить содержимое каналов из рабочего окружения не удалось
(прокси блокирует youtube.com), так что если подпись неточная —
правится в листе 09.

## Как править

Текст — прямо в `index.html`, он читается сверху вниз в том же порядке,
что и на экране. Добавить объект в реестр — скопировать блок `<details
class="reg-row">` и заменить пять полей: номер, название, параметр, срок,
сумма.

Если меняется число разделов, поправьте три места: сам раздел, пункт
в корешке (`nav.rail`) и знаменатель `/09` в штампе.

### Локальный просмотр

```
python3 -m http.server 8000
```

и открыть `http://127.0.0.1:8000/`. Просто двойным щелчком по `index.html`
тоже открывается, но шрифты по `file://` подхватятся не во всех браузерах.

## Проверено

- Ширины от 320 до 2560 px — горизонтальной прокрутки нет нигде,
  штамп ни на одной ширине не перекрывает колонку с суммами.
- Контраст всего текста — не ниже 4.5:1 (WCAG AA) в обеих темах.
- Все 114 символов страницы покрыты подключёнными подмножествами
  шрифтов, включая `₽`, `→` и `≈`.
- Клавиатурная навигация, `prefers-reduced-motion`, `prefers-color-scheme`.

## Про адрес

Репозиторий называется `tea` — от прежнего содержимого. Сайт от этого
работает, но если захочется адреса поприличнее, репозиторий можно
переименовать: адрес станет `https://jkotosmos.github.io/<новое-имя>/`.
Тогда придётся поправить `canonical` в `index.html`, `robots.txt`
и `sitemap.xml`. Свой домен настраивается файлом `CNAME` в корне.
